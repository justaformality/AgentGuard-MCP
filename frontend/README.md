# AgentGuard Dashboard

React + TypeScript + Vite + Tailwind dashboard for AgentGuard MCP.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # type-check + production build
npm run lint
```

The dashboard calls the backend at `VITE_API_URL`, defaulting to `http://127.0.0.1:8000`.

See the [project README](../README.md) for full setup, architecture, and the governance demo.
